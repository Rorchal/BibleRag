# 本地安装向量检索（embed_index.py / search.py）

模型 BAAI/bge-m3 跑在本机 CPU 上，不调任何付费接口。首次运行自动从 HuggingFace 下载模型（约 2.3G），
之后离线可用。需要 Python 3.10 以上，内存 8G 以上，磁盘空出 5G。

## 1. 安装依赖（只做一次）

```bash
# Windows PowerShell / macOS / Linux 都一样
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install sentence-transformers numpy
```

有 NVIDIA 显卡想用 GPU 的，第一行换成 `pip install torch`（装 CUDA 版），
然后把 `embed_index.py` 和 `search.py` 里的 `device="cpu"` 改成 `device="cuda"`。

## 2. 建索引

```bash
cd BibleRag
python embed_index.py
```

首次运行会下载模型，国内直连慢的话先设镜像再运行：

```bash
# PowerShell
$env:HF_ENDPOINT="https://hf-mirror.com"
# bash
export HF_ENDPOINT=https://hf-mirror.com
```

模型缓存在 `~/.cache/huggingface/`（Windows 是 `C:\Users\<你>\.cache\huggingface\`）。
索引写到 `index/bge-m3/`，459 段大约 3 分钟（4 核 CPU）。
以后新增讲道、重跑了切分或问题，再运行一次 `embed_index.py` 即可。

## 3. 检索

```bash
python search.py "以皮代皮是什么意思"                       # 默认权重 标题0.4 / 问题0.4 / 正文0.2
python search.py "以皮代皮是什么意思" --weights 0.5,0.3,0.2 --top 10
python search.py "以皮代皮是什么意思" --norm zscore          # 三路先标准化再加权，权重才是真正的比例
python search.py                                             # 交互模式，:w 0.5,0.3,0.2 改权重，:q 退出
python search.py --queries 查询.txt --json 结果.json         # 批量
```

每次启动要加载模型（约 30 秒），交互模式只加载一次。

## 换模型

`python embed_index.py --model BAAI/bge-large-zh-v1.5`（1.3G，只中文，更快）。
索引按模型名分目录，`search.py --index index/bge-large-zh-v1.5` 指定用哪个。
