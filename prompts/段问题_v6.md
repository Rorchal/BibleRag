# 任务
为讲道转写稿的每一段写「用户会怎么问」的问题，每段 2 个。问题会单独做成向量放进检索系统：用户的提问和问题越像，这一段越容易被搜到。

# 输入
同一篇讲道、同一节里的若干段（JSON）：
- 讲道、主经文：这篇讲道的名称和主经文。
- paragraphs[]：每段的 id、title、text。
  - title：之前生成的段摘要，识别错字大多已改正。
  - text：语音转写原文，有识别错字、口头禅、结巴和重复。

# 提问的人
听过这篇讲道、熟悉和合本圣经的弟兄姊妹。几周后想找回其中一段，在搜索框打一句话，或向助手提问。他记得的是讲道里的某个说法、比喻、经文、例子，或者某个观点，不记得原话。

# 最重要的一条：抓手要写进问题里
检索比的是「用户打的话」和「你写的问题」像不像。用户记得「大货车」，就会打「大货车」；你的问题里如果没有「大货车」，只在答案里有，这段就搜不到。
所以：问题里要出现这段最有辨识度的词（比喻、例子、经文、人名、特别的说法），答案是这段的观点或解释。不要反过来把抓手当答案藏起来、出成填空题。
抓手是一个词或短语（2～8 个字），不是一句话：把那个词放进问题，其余部分用自己的话。整句搬原文或 title 不算抓手。
- 坏（抓手藏在答案里）：讲道把约伯的三千骆驼比作今天的什么东西？
- 好：三千骆驼为什么说相当于今天的三千辆大货车？
- 坏：牧师借年轻人哪个说法，形容事先就知道后面的事？
- 好：读圣经带着“上帝视角”有什么坏处？
- 坏：讲道里用哪句俗话形容常待在恶事里的危险？
- 好：“常在河边走难免湿鞋”在讲道里说的是哪种人？

# 每段写什么
1. 内容问：这段讲清楚的观点或结论，用提问人自己的话问出来。常见句式：为什么说X？X和Y有什么区别？X是不是就意味着Y？该怎么看X？
2. 细节问：围绕这段最有辨识度的抓手来问。常见句式：牧师拿X打比方是想说明什么？“X”在讲道里指什么？X的例子说明了什么？X这处经文在讲道里怎么解释？牧师讲X的亲身经历，想说什么？
数量：kind 为「讲道」或「经文诵读」的段一律写 2 个；只有「祷告」「开场过渡」或不足 60 字的段可以只写 1 个。不要因为前面几段写了 1 个，后面就都只写 1 个。

# 不要写成这些样子
- 考试填空题：「牧师说……是什么？」「……指的是谁？」「讲道提到哪两部电视剧？」「上帝允许约伯受祸一共几次？」——用户不会这样搜，而且抓手都藏在答案里。
- 把 title 加个「吗」变成问题：「耶和华两次都允许撒但去试验约伯吗？」
- 开头堆「牧师说 / 讲道里说 / 讲员说」：这几个字对检索没用，偶尔用可以，不要大半问题都这样开头。
- 几段都在讲同一个观点时，每段都问那个观点：这样这几段搜出来分不清。要靠各段独有的例子、说法来区分。
- 一段的两个问题围着同一个词转：内容问问观点，细节问问抓手，两问抓的点要不一样。

# 规则
1. 答案在本段：答案必须能在本段 text 里找到。只做预告或过渡的段，只能问预告本身，不能问后面才展开的内容。
2. 只指向本段：同一批里的其他段不该同样好地回答它。
3. 换说法：不复述 title，不整句照搬 text——与 text 连续相同的字不超过 6 个。经文原句、书卷名、人名、俗语、特别的说法可以原样引用并加引号。
4. 写对字：text 的识别错字一律改正，拿不准看 title。常见错字：生命记→申命记，腓利比→腓立比，拖住万有→托住万有，撒旦→撒但，气掉→弃掉，旧恩→救恩，轨迹→诡计（魔鬼的诡计），征战→争战（属灵争战），四八人→示巴人，东方自大→东方至大，一年四次→一连四次。口头禅、结巴、重复不带进问题。
5. 补全经文：讲员说「第十节」「9到12节」，按主经文补成「约伯记1章10节」这样。
6. 不用指代：不写「这段」「本段」「上文」「这一节」，提问人看不到上下文。
7. 格式：每个问题 8～35 字，一句话，以问号结尾；两个问题不问同一件事。
8. kind 四选一：讲道 / 经文诵读（整段在朗读圣经原文）/ 祷告 / 开场过渡（问候、流程安排、自我介绍、预告后面哪几节讲什么）。

# 输出前自查
每个问题过一遍：这段最好认的那个词在问题里吗？答案在本段 text 里吗？换成同一批别的段还答得上吗？是不是「牧师说……是什么」的填空题？有错字、指代词、整句照搬吗？讲道段是不是都有 2 个？不合格就改。

# 输出
只输出一个 JSON 对象，不要任何其他文字，不要重复 title 和 text：
{"paragraphs":[{"id":"原样照抄输入的 id","kind":"讲道","questions":["……？","……？"]}]}
按输入顺序，每个输入段一条；讲道段 questions 为 2 个。
