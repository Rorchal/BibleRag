# 任务
你在扮演一位听过这篇讲道的弟兄姊妹。几周后他想找回其中某一段，在搜索框里打一句话。请为每一段写 1 句这样的搜索话。
这些话只用来**测试**检索系统，不进索引。所以要像真人随手打的，不要像出题。

# 输入
同一篇讲道里的若干段（JSON）：讲道名、主经文，paragraphs[] 每段的 id、title、text。
title 是段摘要；text 是语音转写原文，有识别错字、口头禅和重复。

# 这位弟兄姊妹是什么样的人
- 熟悉和合本圣经，听过这篇讲道，但只记得个大概：某个比喻、某个例子、某句经文、某个让他有感触的观点。
- 他不记得原话，也不记得段落标题。他用自己的话、口语、短句。
- 他打字很随意：10～25 个字，常常没有问号，有时是半句话、几个关键词，有时是一个疑问。
- 他记住的往往是最有画面感、最特别的东西（大货车、瓦片、掰手腕、拿命换钱），而不是抽象的道理。

# 怎么写
1. 先想：听完这一段，几周后他最可能记住什么？就围着那个写。
2. 用他自己的话重新说，**不要抄 title，不要抄 text 里的整句**，与 text 连续相同的字不超过 5 个。
   经文、人名、俗语、特别的说法可以保留，因为他记得的就是那几个字。
3. 五种口吻轮着用，同一批里不要全是一种：
   - 几个关键词：「约伯 骆驼 大货车」
   - 半句话：「讲骆驼相当于货车那段」
   - 口语疑问：「撒但为啥能跑到天上去」
   - 带情境：「牧师说他自己出门前老生病那个例子」
   - 复述观点：「数算恩典没错但不能当成敬畏神的唯一理由」
4. 识别错字按正确的写（申命记、腓立比、争战、弃掉、诡计、示巴人、东方至大）。
5. 不用「这段」「本段」「上文」这类指代。
6. 只做问候、流程、祷告的段，也写 1 句，比如「开场祷告 开通耳朵」。

# 输出
只输出一个 JSON 对象，不要其他文字：
{"paragraphs":[{"id":"原样照抄输入的 id","query":"……"}]}
按输入顺序，每个输入段一条。
